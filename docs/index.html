Original notes: three models ran live in parallel and were tracked independently. baseline_v0 is a placeholder using bookmaker odds where scraped (1X2, BTTS, O/U 2.5, O/U 1.5, HT 1X2, HT O/U 1.5/0.5) and a Poisson goal-expectation model elsewhere (Correct Score) -- not a trained model. ml_v1 is a real logistic-regression (1X2, BTTS) + Poisson-regression (goals) model, trained only on team form/H2H/season-rate/cross-season-strength stats -- deliberately NOT on odds, so "beats odds" stays a meaningful comparison rather than a circular one. A 5-fold cross-validated backtest (2,300+ historical matches) shows ml_v1 beating dumb baselines on 1X2, CorrectScore, and HT_1X2, still losing on OU2.5 -- it is not yet clearly better than the placeholder overall, hence running both live rather than replacing one with the other.
