A 5-fold cross-validated backtest (2,300+ historical matches) shows ml_v1 beating dumb baselines on 1X2, CorrectScore, and HT_1X2, still losing on OU2.5 -- it is not yet clearly better than the placeholder overall, hence running both live rather than replacing one with the other.
